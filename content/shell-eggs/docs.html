Shell families

🖥️

Server Shells

SSH (standard, CA-certified, hardened keys-only), Dropbear, Telnet and Mosh listeners for managing the container..

🔁

Multiplexers

tmux, GNU Screen and Zellij persistent sessions that survive disconnects.

🕳️

Tunnels

SSH -L / -R / -D forwarding, X11, rsync-over-ssh and sshfs mounts through an encrypted channel..

🎣

Reverse Shells

Interpreter and netcat-family callbacks: bash, python, PHP, perl, ruby, lua, node, powershell, go, java, groovy, awk, nc/socat and TLS flavors.

🛡️

Secure / Covert

TLS-wrapped shells plus websocket, DNS and ICMP channels for egress-restricted networks.

📡

Bind Shells

Listeners inside the container.

🌐

Web Terminals

Browser xterm.js terminals (ttyd, gotty) and token-authed HTTP exec shells (php/node).

🔬

Debug Shells

sshd -ddd auth debugging, strace-everything login shells, tcpdump capture sessions and a hex-dump socat probe relay..

Prefer one long page? The complete reference with connection commands for every shell lives in SHELLs.md - the same guides the console prints at boot.
