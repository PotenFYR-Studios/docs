Java auto-selection

Leave JAVA_VERSION empty and the launcher picks the right JVM: downloading it on demand into .java/ when the image doesn't ship it. Override with any of: 8172126

Minecraft versionRuntimeNotes
26.x and newerJava 26Future-proofed for the newest releases
1.20.5 – 1.21.xJava 21Standard LTS runtime for modern Minecraft
1.17 – 1.20.4Java 17Caves & Cliffs through Trails & Tales
1.16.5 and olderJava 8First-class legacy modpack support (1.12.2 / 1.7.10)
Proxies / NukkitJava 21Velocity, BungeeCord, Waterfall, Nukkit
Bedrock / PocketMineNative / PHPBDS is a native binary; PocketMine runs on PHP 8.x

Version fallback

MINECRAFT_VERSION accepts latest, latest-snapshot (vanilla snapshots) or an exact version. For Velocity/Waterfall it is the software version (e.g. 4.0.0), for Bedrock the BDS version (e.g. 1.26.44.3). Invalid versions fall back to latest instead of failing the install.

SERVER_TYPE       velocity   # proxy: version = Velocity release
MINECRAFT_VERSION 3.4.0-SNAPSHOT

SERVER_TYPE       bedrock    # engine: version = BDS release
MINECRAFT_VERSION latest
